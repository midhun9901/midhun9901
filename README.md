## 🚀 Featured projects

### 🏺 [Metric Learning for Vase &amp; Urn Retrieval](https://github.com/midhun9901/vase-urn-project)
Content-based image retrieval for archaeological vases — my master's project at FAU.
- Benchmarked **ResNet50 vs DINOv2** backbones and several metric-learning losses (Triplet, ProxyAnchor, ArcFace)
- Best model — **DINOv2 (ViT-S/14) + Triplet loss: 83.4% mAP, 100% recall@10**
- Found and explained two negative results (background removal, pose) instead of hiding them
- End-to-end, reproducible pipeline running on the university **HPC cluster (SLURM)**

`PyTorch` · `DINOv2` · `FAISS` · `metric learning` · `SLURM`

### 🧠 [Deep Learning from Scratch](https://github.com/midhun9901/deep-learning-from-scratch)
The core ideas of modern deep learning, built from nothing, one stage at a time.
- A ~90-line **autograd engine** — the same backprop that powers PyTorch — with a computation graph rendered by the engine itself
- **makemore**: character-level language models (bigram → MLP → …), working toward a small GPT
- Every stage is a self-contained notebook with a written explanation of *why* it works

`Python` · `PyTorch` · `zero-dependency autograd`
